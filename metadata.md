## Metadata Descriptions

### Year
Unique identifier for the dataset's year of collection.

### Collection Name
Represents the dataset collection.

### Location
Specifies the city or region where the dataset was collected.

### Dataset Name
The specific dataset title, often associated with a particular research topic.


| Field Name       | Description                                        |
|------------------|----------------------------------------------------|
| **Year**        | Unique identifier for dataset collection year      |
| **Collection Name** | Represents dataset collection                |
| **Location**    | Specifies city or region of dataset collection    |
| **Dataset Name** | The specific dataset title                        |
